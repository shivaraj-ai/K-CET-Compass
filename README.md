## 📌 About

**KCET Compass** is an AI-powered web application that helps Karnataka CET aspirants predict their best engineering college options based on their rank, category, and branch preferences. Built with pure HTML, CSS, and JavaScript - no dependencies, works offline!

### 🎯 Why KCET Compass?

| Problem | Solution |
|---------|----------|
| ❌ Confusing cutoff lists | ✅ AI-powered predictions |
| ❌ Outdated data | ✅ 5 years of historical data |
| ❌ No personalization | ✅ Rank, category, branch filters |
| ❌ Hard to compare | ✅ Clean, visual college cards |
| ❌ Not mobile friendly | ✅ Responsive design |

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🏛️ **College Prediction** | Enter your KCET rank and get personalized college recommendations |
| 📊 **All Ranks Supported** | Works for ALL ranks from 1 to 300,000 |
| 🎯 **Branch Filtering** | Filter by CSE, ISE, AIML, DS, ECE, EEE, Mechanical, Civil & more |
| 👥 **Category Support** | GM, OBC, SC, ST, EWS with appropriate cutoff adjustments |
| 📈 **Cutoff Ranges** | Shows historical cutoff ranges for each college |
| 💰 **Placement Data** | Median packages and placement statistics |
| ⭐ **NIRF Rankings** | Verified NIRF rankings for all colleges |
| 🎨 **Modern UI** | Clean, responsive design that works on all devices |
| ⚡ **Instant Results** | AI-powered prediction in under 2 seconds |
| 📱 **Mobile Friendly** | Works perfectly on phones, tablets, and desktops |
